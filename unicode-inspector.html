Unicode Inspector

V1.0.0 · Unit eksperimen · Referensi pemetaan Pegon V8.1

Periksa karakter, urutan code point dan perbedaan dua teks. Bukan penerjemah, pemeriksa pelafalan, atau validator lengkap V8.1. Teks diproses lokal; tidak ada pengiriman data oleh aplikasi ini.

01 — Teks pemeriksaan

Urutan logis, bukan urutan visual RTL. Maksimum 10.000 unit UTF-16 per kolom. Input tidak dinormalisasi secara otomatis; textarea browser dapat menyeragamkan akhir baris.

02 — Ringkasan dan perbandingan

Kesamaan NFC tidak berarti identik secara mentah. Kecocokan dengan referensi hanya menguji pasangan yang diberikan, bukan kebenaran linguistik atau kepatuhan semua aturan V8.1.

03 — Register karakter aktual

PosisiKarakterUnicodeNama (subset)Catatan
Nama tersedia untuk subset karakter teknis; kode lainnya tetap ditampilkan. Tanda gabung diperlihatkan dengan lingkaran putus-putus sebagai bantuan visual saja.

04 — Pengujian mandiri

Vektor sintetis menguji pencacahan, perbandingan mentah, normalisasi, tanda gabung, karakter kontrol, dan karakter di luar BMP.
